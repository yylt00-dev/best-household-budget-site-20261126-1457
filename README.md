NestLedger — a household budget planner for the fictional Hartono family: a live dashboard, transaction ledger, monthly budget envelopes, savings goals, bills and six-month reports, all as static files that work offline on desktop and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. The site is plain static files under `app/` — no build step, no network requests, and edits are saved in the browser's local storage.
